## Turn 1 — pytest HTML 테스트 결과·커버리지

### User

```
pytest 시 테스트 결과와 커버리지는 html 파일로 떨어 뜨려라
```

### Assistant (요약)

**목표:** `pytest`만 실행해도 테스트 결과·커버리지 HTML 자동 생성.

**변경**

| 파일 | 내용 |
|------|------|
| `pyproject.toml` | `dev` extras: pytest, pytest-cov, pytest-html |
| `pyproject.toml` | `addopts`: `--cov=src`, `--cov-report=html:htmlcov`, `--html=reports/pytest-report.html`, `--self-contained-html` |
| `pyproject.toml` | `[tool.coverage.run/report]` 설정 |
| `.gitignore` | `reports/` 추가 |

**설치**

```powershell
pip install -e ".[dev]"
```

**검증**

```text
python -m pytest
→ 69 collected, 40 passed, 29 failed (~1.16s)
→ TOTAL coverage 92%
→ reports/pytest-report.html (pytest-html)
→ htmlcov/index.html (coverage.py)
```

**HTML 위치**

| 파일 | 내용 |
|------|------|
| `reports/pytest-report.html` | 통과/실패·traceback·소요 시간 |
| `htmlcov/index.html` | 라인·브랜치 커버리지 |

## 재실행용 프롬프트

**기본 (HTML 2종 자동):**

```powershell
python -m pytest
Start-Process reports\pytest-report.html
Start-Process htmlcov\index.html
```

**커버리지·HTML 리포트 끄기:**

```powershell
python -m pytest --no-cov --override-ini="addopts=-v"
```

**동일 설정을 새 프로젝트에 적용:**

```
pytest 실행 시 테스트 결과와 커버리지를 HTML로 남겨라.
- pyproject.toml addopts: pytest-cov → htmlcov/, pytest-html → reports/pytest-report.html
- dev deps: pytest, pytest-cov, pytest-html
- reports/ gitignore
```
