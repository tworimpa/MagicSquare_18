## 1. Executive Summary

본 세션에서는 `pytest` 기본 실행만으로 **테스트 결과 HTML**과 **커버리지 HTML**이 자동 생성되도록 `pyproject.toml`·`.gitignore`·dev 의존성을 구성했다. `pytest-html`로 `reports/pytest-report.html`(단일 self-contained 파일), `pytest-cov`로 `htmlcov/index.html`이 출력된다. 검증 실행 결과 **69 collected · 40 passed · 29 failed**, **src TOTAL 커버리지 92%**였다. production(`src/`) 로직 변경은 없으며, RED skeleton·AC-FR-01-01 계약 drift 등 기존 실패는 그대로다.

## 3. pytest 기본 옵션 (`addopts`)

```toml
addopts = [
    "-v",
    "--cov=src",
    "--cov-report=html:htmlcov",
    "--cov-report=term-missing",
    "--html=reports/pytest-report.html",
    "--self-contained-html",
]
```

| 옵션 | 산출물 |
|------|--------|
| `--cov-report=html:htmlcov` | `htmlcov/index.html` — 라인·브랜치 커버리지 |
| `--html=reports/pytest-report.html` | 테스트 통과/실패·소요 시간·실패 traceback |
| `--self-contained-html` | CSS/JS 임베드 — 단일 HTML로 공유 가능 |
