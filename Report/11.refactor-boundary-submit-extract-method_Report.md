### 3.2 Extract Method 구조

```text
UIBoundary.submit(matrix)
  → _validate_input_or_error(matrix)     # 입력 계약 → ErrorResponse | None
  → _solve_matrix(matrix)                # Domain 호출 → Solution6 | ErrorResponse
  → _to_success_or_internal_error(result) # 출력 검증 → SuccessResponse | INTERNAL_ERROR
```

| private method | 역할 | 기존 `submit` 대응 줄 |
|----------------|------|----------------------|
| `_validate_input_or_error` | `validate_input_contract` + ErrorMapper | 입력 검증 분기 |
| `_solve_matrix` | solver 호출 + E006/E007 catch | try/except 블록 |
| `_to_success_or_internal_error` | `validate_output_format` + SuccessResponse | 출력 검증·DTO |
