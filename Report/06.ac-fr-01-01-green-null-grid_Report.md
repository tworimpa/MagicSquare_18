## 1. Executive Summary

본 세션에서는 **TDD GREEN phase**만 수행하여 `UIBoundary.submit(None)`이 `INVALID_SIZE` / `"Grid must be 4x4."` 계약을 만족하도록 Boundary 입력 검증을 최소 수정했다. 대상 테스트 1건만 실행·통과했으며, `ui_boundary.py`·Control·Domain·기타 AC-FR-01-02~05 분기는 변경하지 않았다.

| 항목 | 값 |
|------|-----|
| **사전 상태** | RED — `code` 실제 `'INPUT_NULL'`, 기대 `'INVALID_SIZE'` |
| **사후 상태** | GREEN — 1 passed |
| **테스트 수정** | 없음 (assert 유지) |

## 3. 구현 요약

### 3.1 AC-FR-01-01 계약

| 필드 | 기대값 |
|------|--------|
| `status` / type | `"ERROR"` |
| `code` | `"INVALID_SIZE"` |
| `message` | `"Grid must be 4x4."` (문자 단위) |
| `result` | `None` |
| Domain `resolve()` | 호출 없음 (기존 UIBoundary 흐름 유지) |

### 3.2 처리 흐름

```text
UIBoundary.submit(None)
  → validate_input_contract(None) → _InvalidSizeCode
  → ErrorMapper.to_error_response → ErrorResponse
  → to_dict()["code"] == "INVALID_SIZE"
```

### 3.3 기술 메모

- `enum.extend_enum`이 Python 3.13 환경에서 import 불가하여, `ErrorCode` enum 확장 대신 **frozen dataclass `_InvalidSizeCode`**를 `ERROR_MESSAGES` 키로 사용.
- `schemas.py`에 AC-FR-01-01 상수 SSOT 배치 (테스트 내 `PRD_SECTION_8_1_*`와 동일 문자열).
